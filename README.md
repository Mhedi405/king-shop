# KING SHOP — Phone-friendly upload package

This package places all project files in ONE folder so you can select them together from an Android file picker.

## Files
- `server.js` — Node.js/Express backend
- `package.json` — dependencies and start command
- `index.html`, `style.css`, `app.js` — storefront frontend

## Important
This is source code, not a live website. It will not work as a real store until deployed with Node.js hosting, a persistent PostgreSQL database, and environment variables configured securely in the hosting dashboard.
Never commit real passwords, `.env` files, database URLs, or payment gateway secrets to a public repository.
Real payment processing is not active until a valid merchant account and provider credentials are configured.
